## The story

> Every night since the accident, my wife sets a plate for our son at his empty chair, and every morning she clears it away untouched. Last night the plate came back clean, and this morning there was a second plate on the table, set for me.

## How it works

`main.py` (Python 3.13, standard library only) writes the story to `entry.txt` inside the directory given by `MAKEFUN_OUTPUT_DIR`. It never writes anything into the repository directory, and its output is byte-identical across runs.
